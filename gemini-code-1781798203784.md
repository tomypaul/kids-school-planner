# Kids Academic Planner: Architecture & Handoff Document

## 1. Project Overview & Problem Statement
**The Problem:** Crucial academic schedules, test dates, and activity requirements are sent by school teachers via a noisy WhatsApp group. These messages often get lost in the chat history, leading to missed assignments and unnecessary stress. The incoming messages are highly unstructured and frequently mix multiple languages (English, Malayalam, and Hindi).

**The Solution:** A zero-friction, self-hosted Progressive Web App (PWA) that intercepts these WhatsApp messages via the native Android Share Menu, extracts actionable dates and tasks using an LLM (Gemini API), and automatically schedules them into a Google Calendar. 

**The Goal:** $0.00 monthly operating cost using a modern Serverless Edge architecture, with zero reliance on third-party automation tools (like Tasker) or fragile WhatsApp messaging APIs.

---

## 2. System Architecture (The Serverless Stack)
The project relies on a 100% serverless Next.js architecture to minimize operational overhead and hosting costs.

* **Frontend & API Framework:** Next.js (App Router)
* **Hosting:** Vercel (Free Tier)
* **Authentication:** Auth.js (NextAuth) for Google SSO
* **AI/Extraction Engine:** Google Gemini API (2.5 Flash - Free Tier)
* **Integration:** Google Calendar API (v3)
* **Storage (Token Management):** Vercel KV / Upstash Redis (Free Tier) for storing OAuth refresh tokens.

---

## 3. The Core Ingestion Pipeline

### A. The Input Mechanism (Web Share Target API)
Instead of copy-pasting, the app leverages the PWA `share_target` API to integrate directly into the Android OS share menu.

1.  User long-presses the WhatsApp message and taps "Share".
2.  User selects the installed "Kids Planner" PWA.
3.  The OS automatically fires a `POST` request to the application's ingestion API route containing the text.
4.  **Fallback:** The PWA UI also includes a standard `<textarea>` for manual pasting when browsing on a desktop.

### B. The AI Extraction Logic (Gemini API)
The backend passes the raw, multilingual text to the Gemini API. The LLM handles translation, context extraction, and date formatting in a single pass.

**System Prompt Example:**
```json
"System: You are an intelligent calendar assistant. Extract upcoming tasks, tests, and activities from the following school update message. 
The current year is 2026. The text may contain English, Malayalam, and Hindi.
Return ONLY a valid JSON array of objects with the following keys:
- 'subject': The class subject (e.g., English, Malayalam, EVS, Maths)
- 'title': A short, clear title for the calendar event
- 'description': Any additional context or notes
- 'date': The scheduled date in YYYY-MM-DD format
- 'type': 'Test', 'Activity', or 'Homework'

Message to process: 
{USER_MESSAGE}"
